# Design Modrigo Portfolio

## Publish to GitHub Pages

IMPORTANT: Keep `index.html` and the entire `assets` folder together at the repository root.

The correct layout is:

- index.html
- assets/
  - stainform-promo-video.mp4
  - images/

Do not upload only `index.html`, and do not put the files inside an extra nested folder. The image and video paths in the HTML are relative paths and depend on the `assets` folder being beside `index.html`.

## Steps
1. Extract this ZIP on your computer.
2. Open your GitHub repository.
3. Choose Add file > Upload files.
4. Upload `index.html` and the full `assets` folder contents, preserving the `assets/images` folder structure.
5. Commit the changes to the branch configured for GitHub Pages.
6. Wait for GitHub Pages to redeploy, then hard-refresh the website with Ctrl+F5.

The supplied project images are included as-is. The WhatsApp feedback screenshots included here have the client's phone number blurred.
